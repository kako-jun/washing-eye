# Washing Eye

自分の体を洗う、一人称の癒しゲームの試作です。
明るい浴室で視線を落とし、スポンジでこすって泡を立て、シャワーで流します（固定シャワーと手持ちシャワー）。
正面の壁には湯気で曇った鏡があり、シャワーを当てると曇りがしばらく取れます。
ブラウザ単体で動き、スマホでも遊べます。

## 操作

手に持つ道具は「スポンジ」と「手持ちシャワー」のどちらか一方です（同じ手を使うので同時には持てません）。
右下の切り替え、または PC ではキー 1 / 2 で持ち替えます。最初はスポンジを持っています。
上に固定されたシャワー（固定シャワー）は手を使わないので、スポンジと一緒に使えます。

| | スマホ | PC |
| --- | --- | --- |
| 見回す | 端末を傾ける（傾きが使えないときは体の外をなぞる） | 体の外をドラッグ（右・中ボタンなら体の上でも） |
| 持ち替える | 右下の「スポンジ」「手持ちシャワー」 | キー 1 / 2、または右下のボタン |
| 洗う（スポンジ） | 体をなぞる | 体をドラッグ |
| 流す（固定シャワー） | 固定シャワーのボタンを長押し | 固定シャワーのボタンを長押し／Space |
| 流す（手持ちシャワー） | 体・鏡に触れている間、指の先に水が出る | 体・鏡の上で当て先を選び、押している間だけ水が出る |

- 固定シャワーは視線の中心に、手持ちシャワーは指・カーソルの指す点に当たります。泡は水の落ちたあたりから流れます
- 正面の壁の鏡（濃い青灰色の枠）は、少し見上げると自分が映ります。鏡の中の自分には、顔のない丸い頭が付きます（一人称の視界には出ません）
- 鏡は湯気で曇っています。シャワーの水が鏡に当たると（固定シャワーは視線の中心、手持ちシャワーは当て先）、その範囲の曇りが取れ、30 秒ほどかけて再び曇ります
- スポンジでは鏡はこすれません（鏡の上を押すと、体の外と同じく見回しになります）
- 湯気はゆっくり漂い、水が出ている間は増えて、シャワーから離れる向きへ流れます
- 湯気と水しぶきは鏡には映りません（粒が反射の中で大きく膨らんで白く飛ぶのを避けるため。水筋は映ります）
- 手持ちシャワーの当て先は濃い水色の輪の目印で示します（マウスでは押す前から控えめに表示し、水を出している間は濃くなります）
- 手持ちシャワーで水を出したまま体・鏡の外へ動かすと、最後に当てていた点へ流し続けます（泡が流れるのは体に、曇りが取れるのは鏡に当たっている間だけです）
- 手持ちシャワーを持っている間、固定シャワー（ボタン・Space）は使えません（ボタンは押せなくなります）
- 持ち替えると、それまでの動作（こする・手持ちシャワーの水）は止まります。手持ちシャワーに持ち替えると、出していた固定シャワーも止まります
- キー 1 / 2 は Ctrl・Alt・Shift・Meta と一緒に押したとき、文字入力欄にフォーカスがあるときは効きません
- ウィンドウのフォーカスが外れたりタブが隠れたりすると、こする・水を出す動作は止まります

スマホの傾き操作は HTTPS で開いたときだけ使えます（iOS は開始時に許可を求めます）。
開発サーバーを LAN の `http://192.168.x.x:5173` のような HTTP で開くと傾きは届かないため、傾きを試すときは HTTPS で配信してください。
傾きが使えない場合は、体の外をなぞって見回せます。

## 起動

```sh
npm install
npm run dev       # 開発サーバー
npm run build     # 型チェック + 本番ビルド（dist/）
npm run preview   # 本番ビルドを配信
```

URL に `?fps` を付けると、画面右上にフレームレートを表示します。
鏡の反射は低解像度の 8bit の描画先に描きます（PC は長辺 512px・毎フレーム、スマホは長辺 384px・1 フレームおき）。

## テスト

```sh
npm run test      # vitest（泡・体の生成・視線・ポインター・道具の持ち替え・持ち替えと固定シャワーの配線・シャワー入力・シャワーの水・泡を流す中心と鏡の曇りを取る点と水の量・当て先の目印・湯気の漂い・鏡の曇りマスク・鏡と鏡に映る頭（反射の間引き・曇りの見た目の更新・解放）・描き分けのレイヤー・音の一時停止と再開・画面の拡大率の見張り・開始処理・UI）
```

テストは各モジュールの隣に `*.test.ts` として置いています。描画（鏡の映り・明るさ・湯気の見え方）・fps・音の聞こえ方・実機の傾きは対象外で、実機で確認します。

## 構成

- `src/main.ts` 起動とメインループ
- `src/game-start.ts` 「はじめる」で走る開始処理（音の開始と傾きの許可要求）
- `src/tool-control.ts` 道具の持ち替え（HUD・キー 1 / 2）と固定シャワーの入力の配線、HUD・ポインターとの接続口
- `src/scene/` カメラ・ライト・浴室、鏡（反射と曇りの重ね、`mirror.ts`）、描き分けのレイヤー（一人称だけ・鏡だけ、`layers.ts`）、画面の拡大率の見張り、トゥーン材質、輪郭線
- `src/body/` 体のパラメータ（`BodyParams`）と生成、鏡にだけ映る頭（`head.ts`）
- `src/foam/` 泡（InstancedMesh）
- `src/input/` 視線・ポインター操作（スポンジ・手持ちシャワー、体と鏡の当たり判定）・道具の持ち替え・固定シャワーの入力
- `src/fx/` 湯気・シャワーの水・手持ちシャワーの水の落ちる点と泡を流す中心・鏡の曇りを取る点・水の量（`water.ts`）・鏡の曇りマスク（`mirror-fog.ts`）・当て先の目印・音
- `src/ui/` スタート画面・操作案内

Vite + TypeScript + Three.js。
